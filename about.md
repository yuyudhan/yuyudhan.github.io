I'm Ankur Pandey, on GitHub as [yuyudhan](https://github.com/yuyudhan) since 2012.

Most of what I make is open source and written in Rust or TypeScript: [toli](https://github.com/yuyudhan/toli), which turns one coding agent into a small team; [nomouse](https://github.com/yuyudhan/nomouse), for clicking anything without the mouse; [quickhop](https://github.com/yuyudhan/quickhop), a launcher; and [Simple Voice](https://github.com/yuyudhan/simple-voice), for dictation on the Mac. Firmware for my split keyboard is in there too.

Everything else is on the [projects page](/projects/), and I write about how these tools work on the [blog](/blog/).
